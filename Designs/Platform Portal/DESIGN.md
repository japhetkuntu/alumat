## Brand & Style

The Platform Portal pairs a pale slate work surface with exact blue actions and risk-only amber. Low elevation, crisp one-pixel borders, compact data density, and an Inter system make the portal read like a controlled, auditable workspace rather than a marketing dashboard. No product brand name is assumed yet — every page uses the generic label "Platform Portal," ready to be swapped for a real name later.

## Usage

Use this file only as a public design summary for downstream agents. It intentionally omits internal workspace state, prompts, diagnostics, and generation plans.
