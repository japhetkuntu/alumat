# AlumUnion brand kit

## Included assets

- `AlumUnion-logo-horizontal.svg` — primary wordmark for headers, marketing, and partner material.
- `AlumUnion-mark.svg` — square app/social avatar mark.
- `AlumUnion-favicon.svg` — compact browser/favicon source.
- `icons/` — six 48 × 48 SVG navigation and feature icons: community, mentorship, events, directory, partnership, and careers.

## Brand direction

The mark merges an **A** and a **U**: the A stands for alumni achievement; the U curves upward as a symbol of union, belonging, and a network that continues after graduation. The gold point is a shared spark—an introduction, opportunity, or reunion.

| Token | Value | Use |
|---|---:|---|
| Alumni Navy | `#0B1F3A` | Primary backgrounds and core text |
| Union Blue | `#1167A8` | Links, buttons, and the wordmark accent |
| Network Teal | `#20A6A8` | Interaction states and supporting accents |
| Legacy Gold | `#F6C85F` | Highlights, recognition, and small moments of celebration |
| Quiet Slate | `#59718D` | Supporting copy |

## Usage notes

- Prefer the horizontal logo on white, mist, or navy backgrounds; preserve clear space equal to the gold dot’s diameter.
- Use the square mark for app icons, profile images, favicons, and social avatars.
- Keep icons at 20–24 px in interface navigation and retain their original stroke treatment.
- On dark navy, use the mark as supplied; do not recolor the gold detail to white.

The SVG files are vector assets, so they remain crisp at any size and can be edited in Figma, Illustrator, or most browser-based design tools.
