## Brand & Style

Use a calm, trust-first alumni application aesthetic: warm ivory page canvas, white 24px cards, primary color only as an accent and soft tint, semantic status colors kept distinct, Inter for UI/body and Lora for page titles/editorial moments, compact data clarity for payments, and warmer image-led rhythm for community surfaces. Preserve the desktop sidebar/mobile bottom-nav shell and runtime-swappable token architecture. Avoid hardcoded brand colors, marketing-site hero layouts, sharp corners, dense admin styling, and ambiguous payment states.

## Usage

Use this file only as a public design summary for downstream agents. It intentionally omits internal workspace state, prompts, diagnostics, and generation plans.
